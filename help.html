How to use it

This is a browser rebuild of Joe Martin’s January 2007 Sherline Products 60° single-point thread calculator. There are two independent calculators side by side:

  • INCH 60°THREADS — enter Outside Diameter (inches) and Threads Per Inch.
  • METRIC 60° THREADS — enter Outside Diameter (mm) and Pitch (mm).

Those four cells are the only inputs, matching the original spreadsheet. Everything else is calculated and read-only. Values update as you type. Reset returns all four inputs to 0, the sheet’s starting state. Print in the header makes a clean shop printout.

What it calculates

For a bolt (external thread): depth with a P/8 flat, and depth for a sharp vee, each in both inches and millimeters. For a nut (internal thread): recommended hole diameter and a thread depth, again in both units. The inch side also shows pitch in inches and mm; the metric side shows the equivalent threads per inch.

Constants and a spreadsheet quirk

The original sheet uses 0.03937 to convert inches and millimeters (not 25.4), 0.6496 for P/8 flat depth, 0.7578 for sharp vee depth, and 0.5412 for the nut-hole calculation:

Nut hole dia. = OD − 2 × (0.5412 × pitch)

On both sides, the nut row labeled THREAD DEPTH - SHARP VEE (metric label is THREAD DEPTH -SHARP VEE) actually uses the P/8 flat factor 0.6496, not 0.7578. The web app keeps that as written.

If TPI or pitch is zero or negative, pitch/TPI outputs are shown as 0. The original Excel IF would display FALSE for a negative input.

Original spreadsheet

Open Original Spreadsheet View (Sheet1) on the app page for a read-only grid of columns A–I and rows 1–20, including the formulas. Sheet2 and Sheet3 in the workbook are empty. The original .xls file was not modified.
